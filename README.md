Fastmark is a fast, dependency-free drop-in replacement for marked 18.1.3: it renders byte-identical HTML on the CommonMark 0.31.2 + GFM 0.29 spec cases at a fraction of marked's CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
